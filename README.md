# 叶文洁 · 思维视角 Skill

> 文明判断、外部救赎与不可逆选择。

属于 Zero Wong 的[三体人物思维专区](https://github.com/zhaohuang321/three-body-thinking-skills)。

## 内容

- `SKILL.md`：思维模型、调用方式与适用边界。
- `01-writings.md` 等研究文件：来源、人物决策分析与验证记录。

## 使用

可直接下载本仓库，或下载并解压同名 ZIP 完整结构包。将完整目录命名为 `ye-wenjie-perspective`，放入 Codex 的 skills 目录，重新开始会话后调用。

示例：**“用叶文洁的视角，分析这个问题，并指出框架的局限。”**

也可以直接阅读 SKILL.md，把它作为思考与讨论的参考。
